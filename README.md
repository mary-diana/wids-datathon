WiDS Datathon 2025 | fMRI Neuroimaging Classification & Predictive Modeling

A machine learning pipeline built during the WiDS Datathon 2025 competition focused on predicting biological sex and ADHD diagnoses from complex, high-dimensional fMRI brain scan datasets. The project covers the full data science lifecycle—from raw neuroimaging preprocessing and feature selection to model training, hyperparameter tuning, and cross-validation evaluation.

Key Achievements & Technical Highlights
* Team Leadership & Project Management: Led a collaborative data science team, managing sprint deliverables, task delegation, and submission timelines under strict hackathon constraints.

* Large-Scale Data Preprocessing: Cleaned and structured multi-subject neuroimaging data, resolving missing values and normalizing high-dimensional spatial features for optimal model performance.

* Predictive ML Modeling: Developed and benchmarked classification models using Scikit-Learn and TensorFlow to optimize diagnostic accuracy and cross-validation metrics for ADHD identification.

* Iterative Evaluation: Analyzed confusion matrices, ROC-AUC curves, and feature importance metrics to iteratively refine feature sets and prevent overfitting.

Tech Stack
Python • Scikit-Learn • TensorFlow • Pandas • NumPy • Matplotlib / Seaborn
